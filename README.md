# Model Recommendation

An applied AI prototype for comparing and recommending AI/ML models using model metadata and FinOps-oriented information.

## Purpose

The project explores how model selection can combine technical characteristics with operational and cost considerations rather than treating model choice as a purely performance-based decision.

## Repository contents

The implementation includes:

- Model metadata
- FinOps inputs
- Recommendation application
- Retrieval/index components
- Deployment configuration
